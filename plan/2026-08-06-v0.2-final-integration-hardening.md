> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every Critical and Important finding from the V0.2 whole-branch review while preserving the approved stop-before-empirical-execution boundary.

**Architecture:** Add trusted promotion-boundary semantic validation, a durable audit/revision layer, node-scoped acceptance serialization, measured connector acquisition, and scored offline acceptance replays. Existing immutable artifacts remain append-only: revisions supersede old versions and issue revision-bound work orders instead of overwriting history.

**Tech Stack:** Python 3.13, Pydantic v2, Typer, pytest, filesystem-first descriptor-pinned persistence, uv, Ruff, mypy.

**Completion record (2026-08-06):** Tasks 1–10 are complete on `codex/feature/research-orchestration-v0.2` at `16c4527`. The final independent whole-branch review returned PASS with no Critical or Important findings. V0.2 still stops at human approval of `artifacts/analysis-plan.yaml` and contains no empirical execution, paper writing, replication execution, or Tier 2 workflow.

## Global Constraints

- No network access, ICPSR content, Tier 2 execution, or real replication package.
- V0.2 stops at human-approved `artifacts/analysis-plan.yaml`; it does not execute empirical analysis or write a paper.
- All authoritative writes are descriptor-relative, no-follow, single-link, bounded, crash-recoverable, and idempotent.
- Old artifact versions, decisions, orders, submissions, and receipts are never overwritten or silently deleted.
- Every production and test module touched by this hardening plan must be at most 400 lines.
- Each task uses RED -> GREEN TDD, independent review, focused regressions, and full-suite verification before acceptance.
