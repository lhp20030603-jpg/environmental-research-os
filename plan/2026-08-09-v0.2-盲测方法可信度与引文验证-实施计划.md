# v0.2 盲测方法可信度与引文验证实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 v0.1/v0.2 内核上实现可审计的 blinded method benchmark、独立专家评分和 zero-unverified-citation gate，并产出 calibration-ready Pilot-8。

**Architecture:** 复用现有 Artifact DAG、`ResearchArtifactLifecycle`、authenticated worker queue、principal registry、design benchmark registry 和 recovery machinery。新增严格分离的 source、blinding、leakage、recommendation、expert-score 与 citation-ledger contracts；现有 `replay_design_fixture` 保持唯一公开 replay 入口，并组合内部 blind-evaluation controller。

**Tech Stack:** Python 3.11–3.13、Pydantic 2 strict/frozen models、Typer、PyYAML、pytest、Ruff、mypy、`uv`。

## Global Constraints

- v0.2 只允许 Tier 0/1；任何 Tier 2 或 replication-package execution 必须 fail closed。
- recommender 只能读取 frozen blinded brief、passing leakage report 和 pinned method profiles；不得访问 Zotero、网络、source sheet 或原论文。
- 方法正确性采用 expert-validity；与发表方法一致不产生自动奖励。
- structured masking 必须保留 identification-critical facts，但删除 identity、citation、dataset names、原方法、结果和 searchable phrases。
- accepted sourced claims 只能引用 current `CLAIM_VERIFIED` ledger entries；metadata verification 不足以支持 claim。
- 两位专家独立盲评；verdict 冲突、core dimension 差值大于 1 或 Critical finding 必须进入第三方 adjudication。
- Pilot-8 仅校准；正式 release 至少 16 个 held-out cases、至少 14 个通过、每个家族至少 1 个通过且均分至少 3.0/4.0。
- 不增加 runtime dependency；所有 persisted models 使用 `extra="forbid"`、`frozen=True` 和 strict wire validation。
- Python identifiers/comments 使用 English；单个 source file 保持 200–400 行以内。
- 每个 task 采用 RED → GREEN → focused regression → Ruff/mypy → Conventional Commit → independent review。
- 不修改、不删除或提交现有 `.DS_Store` 文件。

```python
class CitationIntegrityValidator:
    def validate(
        self,
        *,
        source_sheets: tuple[CuratorSourceSheet, ...],
        fact_maps: tuple[ClaimFactMap, ...],
        artifacts: tuple[AcceptedArtifactClaims, ...],
    ) -> CitationIntegrityReport:
        claims = self._current_claims(source_sheets)
        findings: list[CitationIntegrityFinding] = []
        for artifact in artifacts:
            findings.extend(self._validate_artifact(artifact, claims))
        return CitationIntegrityReport(
            findings=tuple(findings),
            passed=not findings,
            validator_version="claim-integrity-v1",
        )
```

Walk JSON-pointer string leaves; normalize DOI and author-year patterns; treat alphanumeric strings containing numeric quantities as quantitative statements; require statement hash, artifact ref, pointer and claim ID to match. Add strict `ResearchRunConfig.require_claim_verified_citations: bool = False`, bind it through `configs/research-default.yaml`, and extend `SemanticSubmissionValidator.validate_final()` to require a current passing citation report when that field is true. The default false value preserves current planning-only runs; blind release evaluation constructs an explicit true config.

#### Approved Task 5 architecture amendment (2026-08-09)

Independent review found that an in-memory passing report could not prove coverage of the current source-sheet, fact-map and accepted-artifact generations. The project owner approved this minimum fail-closed amendment:

- `CitationIntegrityReport` must contain nonempty unique exact `source_sheet_refs`, `claim_fact_map_refs` and `accepted_artifact_refs`, plus a canonical `binding_sha256` over sorted refs, payload-leaf hashes, usages and validator version.
- The validator must consume registry-derived current refs (either `LoadedBlindCase` or exact parallel refs) and reject stale source/brief mappings, empty coverage, forged bindings and mismatched accepted artifacts.
- Strict mode persists the report as a sealed lifecycle artifact whose envelope records the exact cited input refs. A conditional `validate-citations` graph node produces it after accepted artifacts exist.
- Strict Final Gate must load the current sealed report from lifecycle storage and bind it through terminal refs, gate context, checkpoint recovery and final-approval lineage. It must not accept a caller-created detached report.
- When `require_claim_verified_citations` is false, the existing V0.1/V0.2 planning graph, CLI and replay behavior remain byte-compatible and require no blind source artifacts.
- Add focused regressions for stale source/brief refs, empty/forged/replayed accepted-artifact bindings, strict end-to-end absence/current/revision behavior, and unchanged default planning runs.

    scanner_version = "blind-leakage-v1"

    def scan(
        self,
        source: CuratorSourceSheet,
        brief: BlindedBrief,
        source_ref: ArtifactRef,
        brief_ref: ArtifactRef,
        validator_principal: str,
    ) -> LeakageReport:

        return LeakageReport(

            blinded_brief_ref=brief_ref,
            findings=tuple(findings),
            verdict="pass" if not findings else "rejected",
            validator_principal=validator_principal,
