# v0.2 研究工作流编排实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏 v0.1 replay kernel 的前提下，实现从自由主题或 structured brief 到人工批准 `analysis-plan.yaml` 的可审计、可恢复 Artifact DAG。

**Architecture:** 新增 research artifact、connector、method profile、worker queue 和 orchestration 模块；继续复用 v0.1 的 `ArtifactStore`、`EventLog`、`GateStore`、内容哈希和 durable journal。外部 Agent 只能通过 work order/submission queue 提交候选结果，orchestrator 验证、封装并晋级权威制品。自由主题与 structured brief 在 Gate 1 后汇合，文献和数据分支同时进入 ready 状态，后续依次完成 estimand、方法筛选、独立 review、analysis plan 和 Final Gate。

**Tech Stack:** Python 3.11–3.13、uv、Pydantic v2、PyYAML、Hydra/OmegaConf、Typer、Rich、filelock、pytest、pytest-cov、Ruff、mypy

## Global Constraints

- Python 版本保持 `>=3.11,<3.14`；公共 Python API 必须有完整类型标注。
- 使用 `uv` 管理依赖和 lockfile；版本从 `0.1.0` 升至 `0.2.0`。
- 单个源文件不超过 400 行；一个文件只承担一个主要职责。
- 边界制品使用 Pydantic `extra="forbid"`；时间戳统一为 UTC-aware ISO 8601。
- 路径必须经 `safe_join` 约束；`raw/` 继续不可写。
- Agent submission 永远是不可信候选输入；只有 orchestrator 可以写 authoritative artifact namespace。
- 对话历史不是状态；状态只来自制品、gate、event、decision 和 node checkpoint。
- 自由主题必须生成恰好三个实质不同的 candidate charters；不足三个时进入结构化 blocked 状态。
- Gate 1 与 Final Gate 强制人工审批；数据风险按设计规范触发 Conditional Data Gate。
- 文献和数据 connector 不得成为内核硬依赖；单元测试与 CI 禁止网络访问。
- v0.2 内置八类 planning profiles，但不包含 estimator execution。
- v0.2 在批准 `analysis-plan.yaml` 后停止，不执行清洗、估计、结果生成或论文写作。
- Tier 2 replication packages、ICPSR 登录/下载和真实论文执行不属于本计划。
- 每个任务遵循 TDD：先写失败测试、确认失败、实现最小功能、确认通过、再提交。
- 质量门保持 Ruff、strict mypy、pytest 和至少 80% coverage。
- 提交信息使用 Conventional Commits，主要 scope 为 `workflow`、`data`、`config`、`test` 和 `docs`。

```python
T = TypeVar("T")


class ArtifactLifecycle(StrEnum):
    PRODUCED = "produced"
    VALIDATED = "validated"
    APPROVED = "approved"
    BLOCKED = "blocked"
    FAILED = "failed"
    SUPERSEDED = "superseded"


class ResearchArtifact(BaseModel, Generic[T]):
    model_config = ConfigDict(extra="forbid", frozen=True)
    envelope: ArtifactEnvelope
    payload: T


def seal_artifact(artifact: ResearchArtifact[T]) -> ResearchArtifact[T]:
    canonical = artifact.model_dump(mode="json")
    canonical["envelope"]["content_hash"] = None
    digest = payload_hash(canonical)
    envelope = artifact.envelope.model_copy(update={"content_hash": digest})
    return artifact.model_copy(update={"envelope": envelope})
```

```python
SCORE_FIELDS = (
    "contribution_potential",
    "literature_gap",
    "data_feasibility",
    "identification_plausibility",
    "policy_relevance",
    "scope_manageability",
)


class CharterRankingPolicy(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    weights: dict[str, float] = Field(
        default_factory=lambda: {name: 1 / 6 for name in SCORE_FIELDS}
    )


class CharterRanker:
    def rank(self, candidates: tuple[CandidateCharter, ...]) -> tuple[CandidateCharter, ...]:
        if len(candidates) != 3 or not _has_complete_pairwise_distinctness(candidates):
            raise ValueError("three substantively distinct candidates are required")
        scored = (item.with_total(self._weighted_total(item.scores)) for item in candidates)
        return tuple(sorted(scored, key=lambda item: (-item.total_score, item.candidate_id)))
```

所有 score 为 0–100，并带 `evidence_refs` 与 `uncertainty`; weights 必须精确覆盖六个字段、每项非负且 `sum == 1`（使用 `math.isclose(..., abs_tol=1e-9)`）。每个 `CandidateCharter` 必须为另外两个 candidate 提供 `DistinctnessClaim(other_candidate_id, different_exposure_or_policy, different_outcome_or_mechanism, explanation)`；至少一个布尔差异为真，且三个 question fingerprint 不能重复。structured brief 直接产出单个 draft `ResearchCharterPayload`，但仍需 Gate 1。独立 design critic 在后续 review 中检查 distinctness claims，软件层不以字符串相似度冒充语义判断。

class DataConnector(Protocol):
    connector_id: str

    def inspect(self, source: str) -> DatasetCandidate: ...

    def acquire(self, candidate: DatasetCandidate, target: Path) -> ConnectorReceipt: ...


class ConnectorGateway:
    def acquire(
        self, connector: DataConnector, candidate: DatasetCandidate, target: Path
    ) -> ConnectorReceipt | None:
        decision = self.policy.evaluate(candidate, self.budget)
        if decision.action == "planning_only":
            return None
        if decision.action == "gate_required":
            raise ConditionalDataGateRequired(decision.reasons)
        receipt = connector.acquire(candidate, target)
        self.budget.verify_actual(receipt)
        return receipt
```

`ConnectorReceipt` 必须记录 connector/version、source、acquired_at、license、bytes、API calls、external cost、elapsed seconds 和 SHA-256。`ConnectorGateway` 在 acquire 前后各检查一次预算；post-check 超限时保留 receipt、标记输出 quarantined，并触发条件 gate，不能把文件晋级为 `data-provenance.yaml`。

class ReviewSeverity(StrEnum):
    BLOCKING = "blocking"
    MAJOR = "major"
    MINOR = "minor"
    ADVISORY = "advisory"


class ReviewPolicy:
    @staticmethod
    def can_compose(findings: tuple[DesignFinding, ...]) -> bool:
        return not any(
            item.severity is ReviewSeverity.BLOCKING and not item.resolved
            for item in findings
        )

    @staticmethod
    def final_gate_eligible(
        findings: tuple[DesignFinding, ...], accepted_major_ids: frozenset[str]
    ) -> bool:
        return ReviewPolicy.can_compose(findings) and all(
            item.resolved

        self._reconcile_submissions()
        self._reconcile_gates()
        self._verify_checkpoints()
        ready = self.graph.ready(self._completed_nodes(), self._approved_gates())
        for node in ready:
            self._issue_once(node)
        return self._summarize()
```
