# V0.3-B Shared Causal-Policy Bundle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Panel FE, IV/2SLS, and sharp local-linear RDD as one trusted local-data bundle on the existing econometrics kernel.

**Architecture:** Extend the current DiD-only authority into a discriminated union of strict method specs, then register three focused recipes behind the existing backend/service/verifier/CLI boundaries. All methods reuse immutable CSV snapshots, the reviewed local R executable, bounded evidence, exact references, recovery, and independent verification; method-specific code is limited to validation, deterministic script generation, output parsing, and diagnostic policy.

**Tech Stack:** Python 3.13, Pydantic v2, Typer, repository-owned R templates, R 4.4.3, `fixest 0.14.0`, pytest, Ruff, mypy, uv.

## Global Constraints

- Do not download data, install packages, access Zotero, or invoke Docker/Podman.
- Use only the already-reviewed local `Rscript` and installed `fixest 0.14.0` for optional real smoke tests.
- Preserve the existing `econometrics.local-analysis.v1` DiD input and `econometrics.local-report.v1` report compatibility.
- Method selection, instruments, controls, fixed effects, cutoff, bandwidth, and sample rules must be declared before execution and cannot change after results are observed.
- RDD is a sharp local-linear useful release with triangular weights; it must state that `rdrobust` robust bias-corrected inference is not included.
- Source CSV bytes remain read-only and are copied only into immutable content-addressed snapshots.
- All new or modified Python and R source/test files must remain at or below 400 lines.
- Every behavior change follows RED-GREEN-REFACTOR; one independent whole-bundle review gates the final release.

- `contracts.py`: existing DiD contracts and shared primitives; exports the final `AnalysisSpec` union.
- `causal_contracts.py`: Panel FE, IV/2SLS, and RDD column/config authorities.

- `_causal_csv.py`: numeric-column, panel-key, IV, and RDD support validation.
- `causal_models.py`: shared finite coefficient/support/configuration models and the three typed results.
- `_causal_outputs.py`: bounded exact-schema CSV/SVG parsing shared by new recipes.
- `_causal_script.py`: deterministic template dispatch and safe R literal rendering.
- `templates/panel_fe.R`, `templates/iv_2sls.R`, `templates/rdd_local_linear.R`: repository-owned estimator scripts.
- `panel_fe.py`, `iv_2sls.py`, `rdd.py`: focused recipe validation/render/parse implementations.
- `recipes.py`: registry and `AnalysisResult` protocol typing.
- `local_backend.py`: method-neutral trusted R backend.
- `report.py`, `service.py`, `verify.py`: method-neutral union persistence and exact output-manifest verification.
- `cli.py`: union spec loading with unchanged commands.
- `docs/guides/local-econometrics.md`: concise operator examples and scientific limits.
