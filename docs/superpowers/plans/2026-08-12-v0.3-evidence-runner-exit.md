# V0.3 Evidence Runner Exit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Complete every Wave-1 method family and produce one immutable blinded
V0.3 exit report that reconstructs all registered green results within tolerance
and detects every seeded assumption or integrity failure.

**Architecture:** Extend the existing trusted-local econometrics registry instead
of creating another runtime. External R packages are acquired into one
content-addressed managed library and used only from repository-generated scripts.
The exit runner and evaluator receive separate projections; the evaluator reopens
immutable analysis references and compares them with sealed expectations.

**Tech Stack:** Python 3.13, Pydantic v2, Typer, `uv`, R 4.4.3, existing
`fixest` 0.14.0 and `did` 2.3.0, managed `rdrobust`, `synthdid`, `metafor`, and
`estimatr`, pytest, Ruff, mypy.

## Global Constraints

- Work only in `.worktrees/v03-did-tier2-pilot`; never implement on `master`.
- Follow RED-GREEN-REFACTOR: every production behavior begins with an observed
  failing test.
- External bytes must come from the approved official URL, be hashed before use,
  and be installed only below the run root.
- Never mutate the system or default user R library.
- Execute only repository-generated R scripts; downloaded author code is data or
  package input, never a direct command.
- Keep method packs and data snapshots independently versioned.
- Preserve exact-reference recovery, no-latest lookup, no caller-authoritative
  success flag, and all V0.2 execution boundaries.
- Every changed Python or R source/test file must remain at or below 400 lines.
- Do not push or merge without a separate user request.
