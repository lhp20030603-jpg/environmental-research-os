# V0.3-A Trusted Local DiD Useful Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a useful, offline, local-CSV DiD/event-study workflow using Research-OS-generated R while keeping third-party replication execution disabled.

**Architecture:** Add a method-neutral local econometrics lane beside the existing fail-closed replication lane. Immutable data snapshots, a trusted local R boundary, typed DiD outputs, and independent verification form the shared kernel; only the `did-event-study` recipe ships now, while later methods reuse the same contracts in bundles.

**Tech Stack:** Python 3.12, Pydantic v2, Typer, PyYAML, immutable `ResearchArtifactStore`, R/Rscript with `fixest` and `did` when locally available, pytest, Ruff, mypy, uv.

## Global Constraints

- Section 13 of `plan/2026-08-04-环境经济学与政策研究操作系统-设计规范.md` governs the three method waves.
- Method packs and data packs remain independent; installing a method never triggers a dataset download.
- V0.3-A accepts local CSV only and never mutates the source file.
- Execute only versioned Research-OS-generated R; reject user or author scripts, expressions, package installation, and network operations.
- The Baker et al. JEL package remains `proposed`, unapproved, undownloaded, and unexecuted.
- The production external `replication run` boundary remains fail-closed.
- Preserve V0.2 planning-only and Tier-2 rejection behavior.
- Every changed Python file remains between 200 and 400 lines unless it is a smaller single-purpose module.
- Use TDD, immutable evidence, exact references, independent recomputation, and Conventional Commits.
- Do not add Panel FE, IV, RDD, RCT, Synthetic Control, measurement, or Meta-analysis execution in this release.

```python
def snapshot_csv(spec: LocalAnalysisSpec, store: ResearchArtifactStore) -> LocalDataSnapshot:
    source = open_regular_nofollow(spec.data_path)
    before = sha256_fd(source)
    parsed = inspect_csv(source, spec.columns)
    ref = store.persist_bytes("local-data-snapshot", read_all(source), producer="local-data-intake")
    after = sha256_path_nofollow(spec.data_path)
    if before != after:
        raise LocalDataChanged("source changed during snapshot")
    return LocalDataSnapshot.from_parsed(ref=ref, sha256=before, parsed=parsed)
```
